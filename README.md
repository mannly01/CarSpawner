# CAR SPAWNER
A mod to spawn all available cars for the Car Mechanic Simulator 2027 Demo.

## REQUIREMENTS
* [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3)

## UPDATE - 1.0.1
* Fixed Bug: After spawning all cars, if the user saved the game and reloaded, the 3 Nevadas would be spawed on top of another car. This caused many issues.

## FEATURES
* Spawn all the available cars with one key. (F3)

## DEFAULT KEYS
* F3: Spawn all Cars.

## DEFAULT SETTINGS (CarSpawner.cfg)
* SpawnCars: F3
- [Keycode Values](https://docs.unity3d.com/ScriptReference/KeyCode.html)

## INSTALLATION (Same as all other MelonLoader mods)
* Install [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3) ([MelonLoader.Installer.exe](https://github.com/LavaGang/MelonLoader/releases/download/v0.7.3/MelonLoader.Installer.exe) recommended)
* Download .zip from [Releases](https://github.com/mannly01/CarSpawner/releases/latest) page
* Unzip the CarSpawner.dll file to Car Mechanic Simulator 2027 Demo\Mods folder
* **The CarSpawner.cfg file is optional but will allow you to edit the default settings**
- Default Folder: \SteamLibrary\steamapps\common\Car Mechanic Simulator 2027 Demo\Mods\
